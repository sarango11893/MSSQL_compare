-----------------------------------------------------
NOTAS
-----------------------------------------------------
* El proyecto WPF original (src/SqlSuite.UI) fue eliminado: solo se podía ejecutar
  en Windows. La interfaz actual es Blazor Server y corre en macOS, Linux y Windows.

* DacFx y Microsoft.Data.SqlClient se ejecutan en el servidor; el navegador solo
  recibe HTML y eventos por SignalR. Por eso la app necesita el runtime de
  ASP.NET Core, no WebAssembly.

* Ejecutar:  dotnet run --project src/SqlSuite.Web
  Abrir:     http://localhost:5199
